# Arquitectura de hardware programable — código y videos de las prácticas

Repositorio que acompaña al libro *Arquitectura de hardware programable: programación de sistemas embebidos* (Luis Serpa, Paul Chasi y Leonardo Bueno, Universidad Politécnica Salesiana). Cada código QR del libro apunta a una carpeta de este repositorio.

| Plataforma | Carpeta | Prácticas |
|---|---|---|
| PIC18F45K22 (Sistemas Digitales I) | `pic18/` | p0 entorno, ALU 4 bits, p1–p4 |
| FPGA Nexys A7 (Sistemas Digitales II) | `fpga/` | p1–p7 |
| STM32F407G-DISC1 | `stm32/` | p0–p4 |
| chipKIT Max32 (PIC32) | `pic32/` | p1–p2 |
| ESP32 | `esp32/` | p1 matriz WS2812, p2 MicroPython GPIO/ADC, p3 Firebase, p4 Adafruit IO |

Lista de reproducción de los videos (YouTube, no listada): https://www.youtube.com/playlist?list=PLeNFvmy-lkMA
